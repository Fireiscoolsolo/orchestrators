# Opus Orchestrator

Version 1.0.0, published as an experimental prerelease in the Orchestrators collection.

See the [installation instructions, usage, verification status, and limitations](.claude/skills/opus-orchestrator/README.md). The skill directory contains its scripts, five agent definitions, configuration, templates, tests, and deterministic demonstration fixtures.

The public distribution excludes local validation sessions, raw transcripts, runtime state, inbox files, and build specifications. Personal usernames in synthetic test paths were replaced with ExampleUser. The original project remains the source of historical evidence.

No license has been selected or applied. See the bundled verification status for live-host evidence and outstanding limitations.
