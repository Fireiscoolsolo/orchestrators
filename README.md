# Orchestrators

This repository contains **Fable Orchestrator v1.0.0**, an experimental Claude Code skill for planning, delegating, reviewing, and integrating multi-step software changes. The Node.js CLI tracks task contracts, dependencies, verification, and recovery.

| Project | Location | Status |
| --- | --- | --- |
| Fable Orchestrator | [fable-orchestrator/](fable-orchestrator/README.md) | Experimental v1.0.0 |
| Opus Orchestrator | `opus-orchestrator/` | Planned |
| Sonnet Orchestrator | `sonnet-orchestrator/` | Planned |

Each project has a top-level directory for its own source and installation instructions. The current Fable build is intended for supervised use on trusted projects. Read the [known limitations](fable-orchestrator/LIMITATIONS.md) before running it.
